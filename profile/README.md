# BareBoard
Free hardware education. We can't open their hardware, so we open our findings.
Live at bareboard.org — board-level teardowns, diagnostics guides, and standard operating procedures for real consumer hardware.
BareBoard preserves datasheets, manuals, and documentation for future generations.
